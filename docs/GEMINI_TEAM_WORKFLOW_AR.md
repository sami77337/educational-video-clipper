# دليل تجريبي: Gemini → المقص البسيط → فريق التفريغ

**الحالة: نسخة تطويرية في PR #56؛ غير معتمدة للتوزيع بعد.**

## النطاق

- يعمل Gemini في المتصفح ويخرج **عناوين الأسئلة وأوقات بدايتها ونهاية أجوبتها**.
- يقرأ «المقص البسيط» رد Gemini بعد لصقه، ويقص ملف فيديو محليًا أو مصدرًا مصرحًا به وفق الوظائف الموجودة.
- **لا يقوم المقص بالتفريغ الصوتي**. يرسل الفريق المقاطع إلى بوت Telegram المعتمد ويتولى مراجعة النص.

## طريقة الاستخدام بعد تثبيت الإصدار واختباره

1. افتح الفيديو في Gemini واستخرج قائمة تشمل **جميع** أسئلة الفيديو.
2. اطلب جدولًا بالأعمدة: «م»، «عنوان السؤال»، «وقت البداية»، «وقت النهاية»، «رابط الفيديو».
3. انسخ الجدول بصيغة Markdown أو TSV، أو اطلب JSON بمفتاح clips.
4. افتح المقص البسيط، اختر ملف الفيديو الموجود عندك (أو رابطًا تستطيع معالجته بصورة مصرح بها).
5. الصق نص Gemini في مربع الرسالة واختر «استيراد Gemini».
6. ستظهر معاينة تتضمن عدد المقاطع والتحذيرات؛ راجع الأسئلة القصيرة والفجوات والتداخلات.
7. بعد اعتماد الاستيراد فعّل/اترك خيار «إنشاء حزمة الفريق»، وشغّل معالجة المقاطع كالمعتاد.
8. راجع MP4 الناتجة، ثم سلّم FATWA_TEAM_PACKAGE.zip للفريق. ملاحظات البدايات والنهايات في Excel لا تغني عن المعاينة البشرية.

## صيغ مدعومة

### Markdown

| م | عنوان السؤال | وقت البداية | وقت النهاية |
|---|---|---|---|
| 1 | هل يجوز الجمع بين الصلاتين؟ | 00:19 | 00:37.500 |
| 2 | ما حكم زكاة المال؟ | 00:38 | 01:45 |

### JSON

~~~json
{
  "video_url": "https://www.youtube.com/watch?v=YOUR_VIDEO_ID",
  "clips": [
    {"id": 1, "title": "هل يجوز الجمع بين الصلاتين؟", "start": "00:19", "end": "00:37.500"}
  ]
}
~~~

### CSV

~~~csv
number,title,start,end
1,هل يجوز الجمع بين الصلاتين؟,00:19,00:37.500
~~~

يقبل أيضًا نسخ الجداول المفصولة بعلامة TAB.

## ما يرفضه المستورد

- توقيت ناقص أو غير مؤكد أو مكتوب null.
- النهاية قبل البداية أو مساوية لها.
- رقم مقطع مكرر.
- رابطان يعودان إلى فيديوهين مختلفين.
- جدول ناقص الأعمدة الأساسية.

لا يُقدّر أوقاتًا غير موجودة ولا يشغّل القص بمجرد الاستيراد.

## ضبط نهاية المقطع

يستطيع المقص حفظ أجزاء الثانية مثل 00:37.500. وإذا لاحظ المراجع أن نهاية جواب مقطع معين تحتاج إضافة نصف ثانية، يمكن تعديل خانة وقت النهاية لهذا المقطع، أو استعمال إعداد «وقت بعد نهاية المقطع» لإضافة هامش إلى جميع المقاطع. افتراضيًا يظل الهامش صفرًا؛ لا نضيف وقتًا خفيًا.

## حزمة الفريق

بعد انتهاء القص بنجاح وخيار الحزمة مفعّل:

- FATWA_CLIPS_INDEX.xlsx — فهرس عربي: السؤال، التوقيت الأصلي، حدود القص الفعلية، اسم الملف، المصدر وحالة التفريغ.
- FATWA_CLIPS_INDEX.csv — بيانات الفهرس قابلة للاستيراد.
- clip_manifest.json — سجل آلي بالمقاطع وروابط المصدر.
- FATWA_TEAM_PACKAGE.zip — الفهرس والمقاطع الناتجة وتقرير القص، **ولا يحتوي الفيديو الأصلي**.

ملفات TXT الخاصة بتفريغ الكلام تُنتج لاحقًا بواسطة بوت Telegram وفريق العمل، ولا تُنشأ افتراضيًا بصورة وهمية داخل الحزمة.

## فحص القبول قبل تسليم البرنامج

- اختبارات Python على GitHub Actions خضراء.
- اختبار EXE على Windows، وليس مجرد اختبار وحدة على Ubuntu.
- تجربة فيديو 5-10 دقائق مع حدود عند نصف ثانية ومقارنة الأوقات الفعلية.
- مراجعة جميع الأجوبة الناقصة أو المقاطع القصيرة غير المتوقعة.
- مراجعة الأسماء العربية داخل ZIP وExcel.
- التحقق من أن النسخة الأصلية لم تتغير، وأن حالة فشل تنزيل/قص لا تظهر «نجاحًا».

لا تُدمج PR #56 أو تُوزّع النسخة للفريق قبل هذه الخطوات.
