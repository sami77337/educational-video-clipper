# Educational Video Clipper

A Windows desktop app for clipping educational videos. This initial version sets up the Python/PySide6 project structure and core utility modules.

## Setup

1. Create a virtual environment:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

## Run

```powershell
python app.py
```

## Test

```powershell
pytest
```
